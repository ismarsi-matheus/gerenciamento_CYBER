# Cyber Security Lock — Painel Administrativo (C# .NET)

Aplicação desktop administrativa do **Cyber Security Lock**, sistema de gerenciamento de senhas desenvolvido como Projeto Integrador no Senac Americana.
A versão web do sistema está em [cyber-security-lock](https://github.com/ismarsi-matheus/cyber-security-lock).

## Funcionalidades
- Login de administrador
- Cadastro de clientes
- Pesquisa e gerenciamento de usuários
- Integração direta com o banco MySQL usado pela versão web

## Tecnologias
C# · .NET Framework · Windows Forms · MySQL

## Como executar
1. Importe o arquivo `db_cyber_security_lock (2).sql` no MySQL.
2. Ajuste a string de conexão nos formulários, se necessário.
3. Abra `Cyber_Security_Lock (P.I.).sln` no Visual Studio, restaure os pacotes NuGet e execute (F5).
